# Meu Caderno de Erros

Questões de concurso erradas viram flashcards, organizados por matéria e assunto e revisados por repetição espaçada.

Como usar: cole a questão, copie o pedido pronto para a sua IA (ChatGPT, Gemini, Claude…), cole a resposta de volta e salve os cards. Os cards e o progresso ficam salvos no navegador; use a aba Backup para guardar uma cópia ou levar o caderno a outro aparelho.
